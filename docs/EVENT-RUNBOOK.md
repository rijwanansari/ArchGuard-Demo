# 10-minute live demo runbook

## 0:00 — Hook

Show the bad architecture.

Say:

> "The developer says: I built this yesterday. Would you approve it?"

## 1:00 — Deterministic governance

Click Evaluate.

Say:

> "Notice something important: the LLM did not decide compliance."

Point at the findings.

## 3:00 — Agent reasoning

Click Ask Governance Agent.

Ask:

> Why did you block this architecture?

Then:

> What should I change?

## 5:00 — AI-specific governance

Point at:

- PII
- AI boundary
- data policy

Say:

> "This is where traditional architecture governance starts struggling with AI-generated architectures."

## 7:00 — Remediation

Load remediated architecture.

Evaluate.

Show:

> APPROVED — 100/100

## 8:00 — Architecture governance principle

Ask:

> "Should I let the agent deploy it?"

Answer:

> "No. The more powerful the agent, the stronger the governance around its tools."

## 9:00 — Future

Show:

Architecture Governance Agent

+ RAG

+ MCP

+ Cloud discovery

+ Security

+ PR remediation

+ Human approval

## 10:00 — Closing

> "The future of Enterprise Architecture isn't more architecture reviews. It's intelligent governance that scales with the speed of engineering."
